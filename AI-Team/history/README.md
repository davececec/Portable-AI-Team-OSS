# 团队完整历史区

`workspaces/` 保存升级前的完整工作区快照，用于在团队跨项目迁移后继续查看项目工单、构建记录、Git 历史和缓存现场。

## 规则

- 快照保持原目录结构和文件内容，不自动合并进当前 `AI-Team/memory/` 或 `AI-Team/project-docs/`。
- 历史快照中的 `AI-Team/tasks/` 是旧版档案，不是当前待办工单。
- IDE 桥接和运行时路径只能指向 `Portable-AI-Team/` 当前实体，不能指向 `AI-Team/history/workspaces/`。
- 升级器会在每次升级前快照当前工作区，并复制项目根下仍存在的 `Portable-AI-TeamV*` 历史目录。
- 整队迁移时复制整个 `Portable-AI-Team/`，不要只复制新版母版的运行文件。
- 对外分发包会排除历史工作区，避免携带私密配置、原始日志、Git 元数据和缓存。

## 查询顺序

1. 先看 `manifest.json` 找到版本、来源路径和快照大小。
2. 再进入 `workspaces/<目录名>/`。
3. 旧项目工单通常位于 `AI-Team/tasks/` 或 `AI-Team/project-docs/<项目>/tasks/`。

快照是不可变历史证据。需要继续演进时，应把稳定结论整理到当前记忆或新的项目工单，不要直接修改旧快照。
